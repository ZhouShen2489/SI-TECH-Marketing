# SI-TECH Marketing

This repository is for SI-TECH / Stitch related marketing, messaging, and promotional materials.

It is set up so the same content can live:

- locally on your Mac
- in GitHub for backup, version history, and collaboration

## Current contents

- `LinkedIn Post/`: LinkedIn post card HTML, export scripts, and PNG output
- `stitch-marketing/`: folders for Stitch market research, campaigns, messaging, and assets
- `scripts/`: helper scripts for GitHub sync and local workflow
- `docs/`: setup notes and update guides

## Recommended workflow

1. Edit files locally in this folder.
2. Preview or export your marketing assets.
3. Use GitHub Desktop or the included script to commit and push changes.
4. Keep GitHub as the cloud backup and shared source of truth.

## GitHub connection

This folder is now a local Git repository.

To connect it to a GitHub repository, you can:

1. Open GitHub Desktop.
2. Choose `File` -> `Add Local Repository`.
3. Select this folder:
   `/Users/zhoushen/Documents/SI-TECH-Marketing`
4. Publish it to GitHub, or connect it to an existing remote repository.

Detailed steps are in [docs/github_sync_guide.md](/Users/zhoushen/Documents/SI-TECH-Marketing/docs/github_sync_guide.md).
