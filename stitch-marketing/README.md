# Stitch Marketing Workspace

Put Stitch market and promotion related materials here.

Suggested structure:

- `campaigns/`: campaign plans, launch notes, calendars
- `messaging/`: taglines, value propositions, copy drafts
- `market-research/`: audience notes, competitor notes, pricing research
- `assets/`: images, logos, references, brand material

This keeps Stitch-specific work separate from one-off deliverables like the current LinkedIn post files.
