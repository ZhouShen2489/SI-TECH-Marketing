# 获客工具集成流程图说明

这份说明对应图 3「具体执行 - 获客流程」里的新增区块：典型获客工具集成流程。

它的目的不是讲复杂 CRM 方案，而是用一张简单清楚的软件集成流程图说明：

```text
客户从 LinkedIn / 官网进入
信息进入 HubSpot
正式沟通发生在 Gmail / Google Meet
团队协作发生在 Slack
ChatGPT 辅助总结、写邮件、准备会议和建议下一步
```

## 核心逻辑

HubSpot 是客户数据中心。

LinkedIn 和官网表单负责带来潜在客户。Gmail 和 Google Meet 负责正式沟通。Slack 负责内部提醒和协作。ChatGPT 负责总结、分析、写邮件、准备会议和建议下一步。

这些软件不是孤立使用的。HubSpot、Gmail、Google Meet、Slack、ChatGPT 以及官网表单，都可以通过原生集成、自动化工具或 API 连接起来，让线索、邮件记录、会议纪要、内部决定和下一步动作在系统之间同步。

页面重点展示 5 件事：

```text
客户从哪里来
信息进入哪里
沟通在哪里发生
团队在哪里协作
AI 在哪里辅助
```

## 图上主流程

```text
LinkedIn / 官网表单
        ↓
     HubSpot
        ↓
Gmail / Google Meet
        ↓
     HubSpot 更新
        ↓
      Slack
        ↓
ChatGPT
        ↓
下一步动作：跟进 / 方案 / Demo / 合作 / 转化客户
```

当前图 3 采用更紧凑的两行闭环流程图表达：

```text
线索入口 → HubSpot → Gmail / Meet → HubSpot 更新
                         ↓
                      Slack → ChatGPT → 下一步动作
                         ↺
            人工确认后把决定和建议回写 HubSpot
```

## 节点短文案

| 节点 | 角色 | 图上短文案 |
| --- | --- | --- |
| LinkedIn | 外呼线索入口 | 寻找目标客户；进行初步触达 |
| 官网表单 | 主动询盘入口 | 接收官网询盘；收集客户兴趣 |
| HubSpot | 客户数据中心 / CRM | 存放客户资料；跟踪客户进展；统一记录下一步动作 |
| Gmail | 正式邮件沟通 | 发送材料；客户跟进；沉淀邮件历史 |
| Google Meet | 会议与需求沟通 | 安排会议；客户沟通；讨论合作 |
| HubSpot 更新 | 客户记录回写 | 补充客户需求；记录会议结论；明确下一步 |
| Slack | 内部提醒与协作 | 团队提醒；内部讨论；协同支持客户推进 |
| ChatGPT | AI 辅助推进 | 总结客户背景；生成邮件内容；准备会议；建议下一步 |
| 下一步动作 | 客户推进结果 | 继续跟进；发送方案；安排 Demo；推进合作；转化客户 |

## 对管理层的一句话说明

我们用 LinkedIn 和官网表单获取客户线索，用 HubSpot 统一存放和管理客户资料，用 Gmail 和 Google Meet 完成正式沟通，用 Slack 做内部提醒和协作，用 ChatGPT 总结客户背景、生成沟通内容、准备会议并建议下一步。

整个流程的目标是把获客过程从零散沟通变成结构化、可追踪、可逐步自动化的客户开发系统。
